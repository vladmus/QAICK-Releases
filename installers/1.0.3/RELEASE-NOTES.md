# QAICK Desktop 1.0.3

This update includes Runner 0.32.46, corrects clipped error messages, and removes the confusing Export JSON button from Runner History. Use **Save Run Result** to save a historical run and **Open Run Result** to reopen it.

Existing History and execution evidence remain unchanged. Older plain JSON exports are not converted into Run Result files by this update.

Components: Studio 0.11.49, Runner 0.32.46, Mock Server 0.8.6, Runtime 0.4.16, Executor 0.4.15, HTTP Executor 0.2.30, Contract 0.7.7. No AI Agent integration.

Save your work and fully close QAICK before upgrading. Preserve your Project and collection files. Existing application data identity is retained.

Linux packaged startup and About 1.0.3 were checked with a separate test profile. Windows and macOS installer contents and metadata were checked; native installation on those systems was not repeated here. Windows is unsigned; macOS is ad-hoc signed and not notarized. Check SHA256SUMS before installation.
